# KazeX Morph

[ブラウザで KazeX Morph を開く](https://yo4e.github.io/KazeX-Morph/)

静止画を順につなぎ、形や照明が移り変わる無音のH.264 MP4を作るツールです。画像を選ぶと、その端末のブラウザで変形・合成・エンコードします。アカウント登録は不要です。

## 使い方

1. 開始画像Aと終了画像Bを選びます。JPEG・PNG・WebPに対応しています。
2. 途中で見せたい画像があれば「中間画像を追加」で選びます。最大10枚まで追加でき、サムネイル横の矢印で再生順を変えられます。
3. 補間方式・FPS・動画全体の長さを選びます。初期設定は「なめらかモーフ」、24 fps、4秒（96フレーム）です。
4. 「MP4を書き出す」を押します。完了後、プレビューで動きを確認し、「MP4を保存」を押します。

| 補間方式 | こんな素材に |
| --- | --- |
| なめらかモーフ（従来） | カメラの構図が近く、物の輪郭や位置が少しずつ変わる2枚。双方向のオプティカルフローを使って両方の元画像を変形します。 |
| カメラモーフ（位置合わせ） | 廊下や建物など、直線を保ちたい場面。特徴点を使って画面全体の移動・回転・ズームを推定します。位置合わせが難しい区間はディゾルブします。 |
| クロスディゾルブ（重ね合わせ） | 同じ構図で照明や色が変わる2枚。元画像の位置を固定して重ねる割合を変えます。 |

動画の縦横比はAを基準にし、長辺を最大1920ピクセル、縦横を偶数に揃えます。縦横比の違う画像は中央を切り抜き、透明部分は黒で合成します。画像の上限は各64 MiB・4000万画素、合計256 MiBです。

長さは1〜30秒、FPSは12・15・24・25・30・48・50・60から選べます。「秒数 × FPS」を1コマ単位に四捨五入し、選んだFPSを保ちます。たとえば25 fpsで1.3秒なら33フレーム・1.32秒です。開始・中間・終了の画像を先頭から末尾までほぼ等間隔に置きます。中間画像2枚・全33フレームなら、1・12・22・33枚目が指定した4枚です。

## プライバシー

GitHub Pagesがページと静的なプログラムファイルを配信します。画像のピクセルはブラウザ内で処理し、完成した動画は端末内のBlobから保存します。このアプリには画像アップロード用のサーバー、アクセス解析、テレメトリー、外部CDNへの実行時依存はありません。

## ローカルで動かす

リポジトリのルートで次を実行し、ブラウザで `http://127.0.0.1:8000/` を開きます。配布用のWebAssemblyモジュールは同梱されています。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

- `render.js` は元画像を読み込み、作業中の区間で必要な画像だけをワーカーへ渡します。
- `render-worker.js` は指定したコマに各画像を配置し、間を補間して順番にエンコードします。
- `engine.js` と `encoder.js` は画像処理とMP4作成を担当します。WebAssemblyのビルド用ソースは `tools/` にあります。

## 書き出しの動作確認

`tests/smoke.cjs` は検証用の4枚を生成し、ブラウザで追加・並べ替え・MP4保存を行います。FFmpegで全33フレームを復号し、時刻と素材の順番を照合します。起動方法とテスト用の依存はファイルの冒頭に記載しています。
